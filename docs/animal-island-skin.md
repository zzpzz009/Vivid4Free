# Animal Island 第二套皮肤

默认保留经典深色。点击标题栏的“经典深色 / 海岛皮肤”，或进入“账号 → 设置 → 界面皮肤”，即可切换。皮肤选择保存在现有的本机 UI 设置中。

## 设计边界

- 两套皮肤共用工作区与创意工坊导航、三栏结构、画布位置和操作流程；不建立另一套业务页面。
- 海岛特征放在组件内部：库自带的纸面素材卡、圆角输入、有机插画和轻微小船摆动。两张素材卡使用库的 `default` 类型与 `none` 纹理，与参数和提示词统一为单层纸面、24px 圆角和 1px 浅边框，不叠加自配颜色、双层缝线或胶带。
- 主按钮与模式菜单共用一整块胶囊背景、边框和按压效果。预览与放大切换只改变模式，控件的位置与形状保持一致。
- 主色、文本、表面、边框、焦点与圆角统一映射到库的主题变量；卡片不加浮起阴影，主操作使用库规定的暖色堆叠阴影。常规 Button、Switch、Tabs 保留库的组件配色；预览／放大操作保留强调调整之前的 40px 连续胶囊与取消比例；主色用于操作组，工作区导航采用中性色选中态。
- 减少动态效果设置会关闭动画；原图、结果图与图库图片保持原有色彩。

## 实现

项目使用 Vue 3，因此采用同作者的 [animal-island-vue](https://github.com/guokaigdg/animal-island-vue)，锁定 1.4.0；它是 [animal-island-ui](https://github.com/guokaigdg/animal-island-ui) 的 Vue 版本。

- 实际使用库中的 Button、Card、Switch、Tag、Progress 和 Icon。原生输入框保留已有标签、校验和事件契约，外观按主题适配。
- `useUIStore` 保存皮肤；根元素的 `data-vivid-skin` 控制样式，因此传送到 body 的图片预览与菜单也能继承皮肤。
- Tailwind 的既有颜色使用 RGB 变量和原始色值回退，保留透明度修饰和经典配色。
- 字体随构建本地提供，样式不依赖在线字体服务。第三方说明随前端产物输出到 `THIRD-PARTY-NOTICES.txt`。
- 不修改 CF、模型、任务服务、账号协议或现用安装目录。

配色依据为上游 [design-tokens.md](https://github.com/guokaigdg/animal-island-ui/blob/main/docs/design-system/design-tokens.md) 和锁定 Vue 包的 `dist/index.css`：正文 `#725d42`、标题 `#794f27`、辅助文字 `#9f927d`、主色 `#19c8b9`、内容底 `#f7f3df`、输入底 `#fffbe7`。Tabs 的 `#0cc0b5` / `#fff9e3` 来自包内选中态；常规按钮采用包内奶油底；工作台主操作使用库的主色底、棕色文字和 `#bdaea0` 堆叠阴影，禁用时使用纸底虚线轮廓。工作区导航使用透明底、棕色文字和短下划线，不套选中填色或包围边框。自定义样式不引入新的色值。

字体使用 Nunito + Noto Sans SC，补齐 `@apply` 固化的导航和操作按钮 Roboto 覆盖。原图／结果图标签共用暖棕文字、奶油实底和轮廓，避免白字落在浅色画布上。空素材文案直接说明当前状态及导入／使用路径；海岛皮肤的 Ready 显示为“准备就绪”。

字体字距遵循正文／输入 `.01em`、按钮／标题 `.02em`；经典皮肤保持原来的字距与字体。标题栏的皮肤图标随当前皮肤使用深灰／紫色或薄荷／奶油色。

主色集中用于预览／放大操作、资源选中、焦点和关键状态；两张上传卡共用中性纸色，避免大面积主色与多种卡片底色争夺注意。参数数值采用库原生 Tag，操作反馈与运行包进度采用同一款 forest-grove Progress。海岛提示卡使用纸色底与语义边线，取消原有旋转彩色边框；经典皮肤保留原来的提示样式。

整体层级由表面角色建立：外围使用库的 secondary 沙色底，素材、参数与提示词使用 content 纸色，提示词只保留输入框这一层；历史不套底色，通过原有分割线与画布区分，中央画布保持清晰的 bg 表面。资源纸面与画布的顶部、底部对齐，但不改变三栏外框的坐标和尺寸。标题采用 14px／600，正文与辅助说明采用 12px，空画布主标题采用 18px；不为局部控件额外放大字号或添加饱和色块。

预览／放大按钮保留 `9ffbd68` 中的尺寸、比例、阴影及取消按钮，可用操作组使用库主色和对应的 hover／active 态，禁用时使用虚线轮廓；保留两部分连续无缝的操作胶囊。移除新增按钮图标和操作区提示行，画布说明仍随模式切换。参考图已选时，镜像与清空分别位于两侧；镜像选中态使用库的主色浅底与棕色字，避免白字落在浅色表面。

## 验证与交付范围

皮肤回归用例位于 `client/tests/e2e/skins.spec.js`，覆盖：

1. 双向切换保留上传预览、参数和开关状态，刷新恢复选择。
2. 设置选择、表单原生校验与 body 中的图片预览。
3. 小窗口、键盘导航及减少动态效果。
4. 经典与海岛皮肤的标题栏、导航、侧栏、画布和资源面板坐标／尺寸差异不超过 1px；预览与放大模式均验证按钮与下拉部分无空隙。
5. 导航、操作按钮、输入与对比标签使用指定字体，且本地字体文件实际加载；对比标签的文字与背景颜色符合规范。
6. 中性素材卡、参数标签、库按钮的实际校验反馈、提示关闭和运行包进度数值。进度的可访问名称由外层提供，以避开当前包内连字符属性未输出的问题。
7. 主色可用操作与虚线禁用态、工作区无填色选中态、历史分割线与透明背景、侧栏单层纸面、镜像和清空互不遮挡、实际预览提交和结果展示、放大模式与画布文案同步。

浏览器用例使用隔离夹具。Electron 检查使用独立用户目录和测试端口，不复制账号凭据，不启动或修改现用 CF。真实历史图片的显示与对比通过本机服务只读检查。
